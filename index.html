Core Capabilities

What the app does

The four functional pillars of the Humbu mobile client, each handled by a dedicated module in the codebase.

🔐

User Authentication

Sign-up, login, and session handling so users reach their own account-scoped data.

📦

Product Catalog

Browsable product listings with detail views, backed by the Humbu service layer.

🛒

Shopping Cart

Add, adjust, and review items before checkout, with cart state persisted across screens.

🧾

Order Management

Place orders and track their progress from a dedicated orders view.

Setup

Run it locally in three commands

Clone the repository, install dependencies, and start the Expo dev server. Scan the QR code with Expo Go, or press a / i to launch an emulator.

terminal 
# 1. Clone
git clone https://github.com/Humbulan/humbu-mobile-app.git
cd humbu-mobile-app

# 2. Install dependencies
npm install

# 3. Start the Expo dev server
npx expo start

Contributing

How to contribute

Contributions are welcome. Whether it is a bug fix, a new feature, or a documentation improvement, the process is the same.

Fork the repository

Click Fork on GitHub, then clone your fork: git clone <your-fork-url>

Create a branch

Work on a feature branch, not main: git checkout -b feature/your-change

Make your changes

Follow existing code style. Test with npx expo start on both platforms.

Commit clearly

Use descriptive messages, e.g. fix: correct cart total rounding.

Open a pull request

Push your branch and open a PR against main. Describe what changed and why.

Review & merge

A maintainer reviews your PR. Once approved, it is merged.
